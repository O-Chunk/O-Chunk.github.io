AI-team 개인정보처리방침

시행일: 2026년 11월 25일

AI-team(이하 "이 앱")은 개발자 O-Chunk가 본인만 사용하기 위해 만든 개인용 프로그램입니다. 이 문서는 이 앱이 Google 계정 데이터를 어떻게 다루는지 설명합니다.

1. 사용자

이 앱의 사용자는 개발자 본인 한 명입니다. 다른 사람에게 제공하거나 판매하지 않습니다.

2. 접근하는 Google 데이터

  • Google 캘린더 (calendar.events, calendar.app.created): 수업·과제·시험 일정을 이 앱이 만든 캘린더에 추가·수정·삭제합니다.
  • Google 드라이브 (drive.file): 이 앱이 올린 파일(강의자료, 수업 녹음, 노트)만 읽고 씁니다. 이 앱이 만들지 않은 드라이브 파일에는 접근하지 않습니다.

3. 데이터 저장과 공유

  • Google 로그인 정보(토큰)는 개발자 본인의 노트북에만 저장되며, 다른 서버로 보내지 않습니다.
  • Google 데이터를 제3자에게 판매·공유하거나 광고에 사용하지 않습니다.
  • 수업 노트를 만들 때 수업 내용 일부가 개발자 본인이 구독한 AI 서비스(Anthropic Claude 등)에 전달될 수 있습니다. 이는 개발자 본인의 학습 목적에 한합니다.

4. 보관과 삭제

개발자는 언제든 Google 계정의 타사 앱 권한에서 이 앱의 접근을 해제할 수 있으며, 노트북의 토큰 파일을 지우면 이 앱은 더 이상 Google 데이터에 접근할 수 없습니다.

5. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
